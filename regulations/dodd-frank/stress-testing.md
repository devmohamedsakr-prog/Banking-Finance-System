# Dodd-Frank - Stress Testing Requirements

## Annual Stress Test

### Scenarios

**Severely Adverse Scenario:**

Macroeconomic Variables:
- Unemployment: +4% (rises to 13%)
- Real GDP: -2.5% (contraction)
- Housing prices: -25%
- Stock market: -60%
- Corporate spreads: +600 basis points
- Treasury yields: +100 bps

**Adverse Scenario:**

- Unemployment: +2.5% (to 9%)
- Real GDP: -1% (slight contraction)
- Housing prices: -12%
- Stock market: -30%
- Corporate spreads: +300 bps

**Baseline Scenario:**

- Unemployment: 4.5% (stable)
- Real GDP: +2% (normal growth)
- Housing prices: +2%
- Stock market: +5%
- Corporate spreads: Stable
```

## Capital Projection

```
Example: Large Bank Stress Test Results

Starting Capital Ratio (CET1):
- Actual: 11.5%

Projection Under Severe Stress:
- Pre-provision net revenue: -$50B
- Loan losses: -$150B
- Trading losses: -$30B
- Net income: -$230B
- Projected CET1 ratio: 8.1%

Minimum Requirement: 5.5%

Stress Test Result: ✅ PASS
(Still above minimum after stress)

Capital Buffer Needed:
- Current: 11.5% - 5.5% = 6.0% buffer
- Can withstand up to 6% decline in capital
```

## Dividend Restrictions

```
If Bank Falls Below Threshold:

CET1 Ratio <7%:
- Dividend capped at $0/share
- Share buybacks halted
- Compensation restrictions

CET1 Ratio 7-8%:
- Dividend limited to 25% of earnings
- Buyback restrictions

CET1 Ratio >8%:
- Normal dividend policy allowed
```

## Compliance Checklist

- [ ] Severely adverse scenario modeling
- [ ] Adverse scenario modeling
- [ ] Baseline scenario modeling
- [ ] Capital projections generated
- [ ] Results reviewed by Board
- [ ] Stress test submitted to Fed
- [ ] Public disclosure of results
- [ ] Remediation plan if needed
