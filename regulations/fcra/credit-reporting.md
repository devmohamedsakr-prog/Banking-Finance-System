# FCRA - Fair Credit Reporting Act Compliance

## Consumer Rights

### Access to Credit Report

Every consumer has the right to:
1. Free annual credit report from all 3 bureaus
2. Know what's in their file
3. Get score and reasons for denial

### Dispute Resolution

```
Process:

1. Submit Dispute
   - Consumer files dispute form
   - Mails to credit bureau
   - Include explanation (50 words max)

2. Bureau Investigation (30 days)
   - Contact furnisher (lender)
   - Verify accuracy
   - Re-investigate if requested

3. Furnisher Response (30 days)
   - Confirm accuracy or
   - Correct/delete item

4. Bureau Update (5 days)
   - Unverifiable items = DELETE
   - Corrected items = UPDATE
   - Send corrected report to consumer

5. Notification
   - Send corrected report
   - Notify all who received old report (in last 6 months)
   - Provide dispute statement
```

### Fraud Alert & Credit Freeze

```
Fraud Alert:
- Lasts 7 years
- Requires creditors to verify identity
- Free to place
- Can be removed online

Credit Freeze:
- Lock report from credit inquiries
- Creditors cannot access (no new credit)
- Lasts indefinitely
- Can temporarily thaw

Extended Fraud Alert (ID Theft):
- Lasts 7 years
- Available after reporting identity theft
- More intensive verification required
```

## Employer Use of Credit Reports

```
Restrictions:

Can Use Credit Report:
- With written consent from employee
- For hiring decisions
- For promotion decisions
- Only if job-related

Cannot Use:
- Without consent
- For discriminatory reasons
- To violate Fair Lending laws
- For marketing

Adverse Action:
- If denied based on credit report
- Must notify employee
- Provide copy of report
- Explain right to dispute
```

## Penalties

```
Civil Liability:

Per Consumer:
- Minimum: $100
- Maximum: $1,000
- Actual damages (if greater)
- Attorney fees
- Court costs

Class Actions:
- Class members + damages
- Can reach millions per case

Criminal:
- Up to 5 years prison (willful)
- $5,000 fine

Recent Examples:
- Equifax: $700M (2017 breach)
- TransUnion: $100M (inaccurate reporting)
```

## Compliance Checklist

- [ ] Consumer consent obtained before report pull
- [ ] Accurate data in files
- [ ] Dispute procedures in place
- [ ] 30-day investigation timeline met
- [ ] Adverse action notices sent
- [ ] Privacy notices provided
- [ ] Annual training conducted
- [ ] Audit completed
